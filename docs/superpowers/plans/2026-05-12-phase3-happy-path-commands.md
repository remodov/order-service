# Ф3 — Happy-path команды (UC-1, синхронная часть) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline — `/ucp-*` скиллы через `Skill` tool в текущей сессии, не форком). Steps use checkbox (`- [ ]`).
>
> **ВАЖНО (CLAUDE.md):** шаги со ссылкой на `/ucp-*` — вызов скилла через `Skill`, не пересказ. Скиллы запускаются последовательно. Авто-ревью сразу после design-скилла — по запросу; обязательный review — для рукописного кода. DDL — `/ucp-pg-schema-review`.

**Goal:** Реализовать синхронную часть UC-1 — REST-эндпоинты создания/редактирования/подтверждения черновика заказа: OpenAPI-контракт + DTO + контроллеры, UseCase+Handler для `CreateOrder` (с идемпотентностью), `AddItem`/`RemoveItem`, `ApplyPromo`/`RemovePromo`, `ConfirmOrder`, query `GetOrderById` (write-side, для read-your-own-writes); out-adapter Catalog (REST sync — валидация товаров/цен/промокодов) с Resilience4j; единая обработка ошибок (RFC 9457 ProblemDetails). Без Kafka/саги (Ф4), без Read Model (Ф5), без auth (Ф7 — пока эндпоинты открыты как на профиле `local`).

**Architecture:** Hexagonal — REST DTO/controller в `adapter-in-rest` (OpenAPI-first, openapi-generator `interfaceOnly`), UseCase+Handler в `core/usecase/command|query/` (`UseCaseCommand`/`UseCaseQuery` маркеры из `ru.vikulinva:usecase-pattern`, `@RequiredArgsConstructor`, `@Transactional` на handler'е), `OrderRepository` (Ф1/Ф2) для записи, новый `CatalogPort` (`core/port/out/`) реализуется в `adapter-out-catalog` (Resilience4j-обвязка на adapter-методах, не на generated client), `IdempotencyKeyRepository` port + jOOQ-impl (расширение Ф2). Ошибки: иерархия `OrderDomainException` (Ф1) + `ValidationException`/`IntegrationException`/`TechnicalException` (cross-cutting) → `GlobalExceptionHandler` `@RestControllerAdvice` в `adapter-in-rest` → `ProblemDetail` (RFC 9457) с `code` из `13-errors`.

**Tech Stack:** Spring Web (REST), openapi-generator 7.10 (`spring`, `interfaceOnly`), Jakarta Validation, `ru.vikulinva:usecase-pattern(-starter)`, jOOQ (idempotency_keys), Resilience4j 2.2 (Catalog), `spring-restclient`-generated Catalog client (openapi-generator) либо ручной `RestClient`, MapStruct (REST-DTO ↔ UseCase), Testcontainers PG + WireMock (Catalog) для интеграционных тестов.

**Где мы:** Ф0+Ф1+Ф2 готовы. `core` — домен `Order` + `OrderRepository` + `core/service/{DateTimeService,UuidGenerator}` + `core/port/out/ExternalEventPublisher` + доменные исключения. `adapter-out-postgres` — `JooqOrderRepository` + outbox-relay; схема `v-1.0` включает `idempotency_keys (idempotency_key text PK, request_hash varchar(128), order_id uuid, created_at timestamptz)`. `adapter-in-rest/build.gradle.kts` — openapi-generator настроен (`generatorName="spring"`, `interfaceOnly`, `inputSpec=src/main/resources/openapi/order-service.openapi.yaml` — сейчас placeholder `paths: {}`, `apiPackage=…adapter.in.rest.generated.api`, `modelPackage=…generated.model`), есть spring-boot-starter-web/validation/security/oauth2-rs/mapstruct. `adapter-out-catalog/build.gradle.kts` — `spring-boot-starter-web` + `resilience4j-spring-boot3` + WireMock в тестах (openapi-generator плагин НЕ подключён — добавить если генерим client из spec, или писать `RestClient` руками). Профили: `local` — security permitAll, `application.yml` имеет `clients.catalog.base-url` + `resilience4j.{retry,circuitbreaker,timelimiter}.instances.catalog`. Спека: `docs/spec/07-order-service-commands.md` (CreateOrder/AddItem/RemoveItem/ApplyPromo/RemovePromo/ConfirmOrder), `13-order-service-errors.md`, `14-order-service-integrations/order-service-to-catalog.md` + `order-service-from-customer-bff.md`, `06-order-service-rules.md` (BR-010 идемпотентность, BR-002/013 confirm). Style-guides: `.claude/docs/{rest-api-rules,usecase-pattern-rules,error-handling-style-guide,resilience-rules,validation-rules,jooq-rules}.md`. Roadmap — `docs/superpowers/specs/2026-05-11-order-service-implementation-roadmap-design.md`. Долги из Ф1/Ф2: HTTP-маппинг исключений (делается здесь), `Address` шифрование (Ф7), payload-поля событий vs spec-контракт (Ф4).
